Questions, bug reports and feature requests: open an issue on GitHub. We usually answer within two business days. Please include your macOS version, the device type and, if possible, a saved traffic log (Traffic tab → Save…).

Getting started

  1. Try the demo: on the welcome screen choose “Try the Demo”, or use File → Add Demo Devices. Three simulated devices start on 127.0.0.1:1502–1504.
  2. Add a device: click Add Device, choose Modbus TCP, RTU (serial) or RTU over TCP and enter the address, unit ID and timeout.
  3. Discover: select Discover Devices in the sidebar and scan a subnet (e.g. 192.168.1.0/24) or a serial bus.
  4. Add points or use the Register Browser and choose “Add as Point”, then click Connect & Poll.

Troubleshooting

  • Timeouts on RTU: check baud rate, parity and stop bits (8E1 is the Modbus default), A/B wiring, termination, and increase “Delay between requests”.
  • Illegal Data Address (02): the register does not exist on the device. Many manuals use 1-based (40001) numbering — U-Modbus uses 0-based protocol addresses; enable Settings → Show addresses as Modicon to compare.
  • Strange float or 32-bit values: try another byte/word order (CDAB is common).
  • No serial port listed: connect the USB-RS485 adapter and click refresh. Adapters appear as /dev/cu.* devices.
